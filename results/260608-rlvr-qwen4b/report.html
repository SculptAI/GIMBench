分类分析

推理任务（GPQA / MMLU-Pro / QASC / MedMCQA）

GIM 训练严重损害推理能力。 Base → SFT 下降 7-33pp。RL 训练部分恢复（GPQA +8pp, MMLU-Pro +6pp），但仍远不及 base。
RL 恢复率：GPQA 36%，MMLU-Pro 18%。

结构化任务（Code / Match / CV）

GIM 训练大幅提升结构化任务。 CV 从 0.125 飙升到 0.653（+53pp），Code +6.5pp，Match +5.7pp。
RL 在此基础上进一步微调，CV 达到 0.659（最优）。

SciERC

Base 最强（0.066），SFT/RL 略有退化。4B 模型的 SciERC F1 远高于 1.7B（0.057 vs 0.022）。

结论：GIM 训练（SFT+RL）的本质是用推理能力换取结构化任务能力。RL 训练在 SFT 基础上部分恢复了推理能力（GPQA +8pp, MMLU-Pro +6pp），同时保持了结构化任务的优势。

与 1.7B 对比：4B RL 在全部 8 个指标上超越 1.7B 最佳，平均提升 +8.6pp。模型越大，RL 效果越好、退化越小。
